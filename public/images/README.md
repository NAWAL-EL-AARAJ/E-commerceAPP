# Images du site MERHAS

Dépose ici les fichiers aux chemins exacts ci-dessous. Tant qu'un fichier est
absent, le site affiche un dégradé « blush » à la place (aucune image cassée).

| Chemin | Contenu | Format conseillé |
|---|---|---|
| `logo-merhas.png` | logo MERHAS (header, footer, menu mobile) | PNG, fond transparent de préférence |
| `hero/hero-1.jpg` … `hero/hero-3.jpg` | carrousel accueil | ~1600×1000 paysage |
| `produit-phare/jersey-liquide.jpg` | portant de foulards | ~1400×900 |
| `univers/box.jpg` | coffret rose | ~900×1100 portrait |
| `univers/video-poster.jpg` + `univers/video.mp4` | poster + vidéo | ~1200×800 |
| `univers/script.jpg` | foulard drapé (fond accent manuscrit) | ~900×700 |
| `apropos/image1.png` (portrait), `apropos/image2.png` (paysage) | ambiance marque — page À propos | image1 ~900×1100, image2 ~1200×800 |
| `placeholder-produit.jpg` | image produit par défaut | carré ~800×800 |

Les images des produits (best-sellers, boutique, fiche produit) viennent de
Supabase (`produits.image_url`), pas de ce dossier.
